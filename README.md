# Murree Karwan Goods Forwarding Agency Portal

A professional, high-performance full-stack business portal for **Murree Karwan Goods Forwarding Agency** — a goods transport, warehousing, and logistics company based in Pakistan.

## 🚀 Features
- **Modern UI/UX**: Premium navy-themed dashboard built with React and styled with custom glassmorphism Vanilla CSS.
- **Quote / Inquiry System**: Interactive Multi-Step booking form for Cargo Consolidation, Whole Truck Charters, Factory Transport, and Relocations.
- **Gmail Notifications**: Backend integrated with Nodemailer to forward quote requests directly to `mkgforwardingagency@gmail.com`.
- **Database Logs**: Persistent table logging in MySQL to track and review all customer submissions.
- **Performance & Load Protection**: Equipped with MySQL connection pooling and Express rate-limiters.
- **SEO & Socials**: Built-in dynamic sitemaps, robots crawler policies, and floating WhatsApp operator integration.

## 🛠️ Tech Stack
- **Frontend**: React.js (Vite) + Vanilla CSS
- **Backend**: Node.js + Express
- **Database**: MySQL (using `mysql2/promise`)
- **Email Delivery**: SMTP via Nodemailer

## 💻 Local Quick Start
1. Ensure **MySQL** is running on your system.
2. Configure your database password and Gmail App Password in `backend/.env`.
3. Double-click the **`run_project.bat`** file in the root directory to spin up the backend, frontend, and open your web browser automatically!
